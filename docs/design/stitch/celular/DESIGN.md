## Brand & Style
The design system positions personal autonomous intelligence not as an intimidating terminal or cold enterprise utility, but as a squad of poised, organic, and ultra-competent kinetic companions. The atmosphere is deeply confident, tactile, and quiet—prioritizing serene control over cognitive overload. 

The aesthetic fuses **Tactile Modernism** with subtle **Frosted Glassmorphism**:
- True OLED obsidian depths anchored by ultra-fine optical hairline rims in dark mode.
- Ceramic, warm alabaster parchment with butter-cream and stone underpinnings in light mode.
- Distinct companion signatures expressed through vivid functional chromatic markers (Cobalt, Jade, Violet, Sunset, and Marigold), harmonized under a high-potency Electric Topaz core accent.
- Living geometry: UI structures maintain sweeping 24px–28px organic curves, pill-capsule touch targets, and rhythmic micro-interactions that feel responsive, living, and deliberate.

## Typography
Typographic scale tuned for modern Android viewports (1080x2400 pt density / ~400-440 dpi):
- Headlines rely on **Plus Jakarta Sans** with geometric, warm humanistic stroke terminals to convey confidence and conversational ease in Brazilian Portuguese.
- System feedback, telemetry indicators, status states, and timestamps utilize **Inter** to ensure maximum glyph distinction and condensed readability at compact sizes (`label-caps`, `label-mono-sm`).
- Dynamic localized text rules: Brazilian Portuguese verbs and status labels (e.g., "Sincronizando tarefas prioritárias") require ~18% more horizontal bounding width than English equivalents. Keep container constraints resilient with auto-wrapping or designated multi-line limits.

## Layout & Spacing
Designed around Android handheld geometry (20:9 aspect ratio, 1080x2400 viewport reference):
- **Base Rhythm:** Strict 4px/8px modular spacing baseline.
- **Canvas Margins:** Fixed `1.25rem` (20px) outer edge margins ensure comfortable thumb reach while clearing curved screen hardware perimeters.
- **Bot Stream Grid:** Single-column layout for conversation threads and activity timelines with `gutter` (`1rem` / 16px) separation. Two-column symmetrical grid (`space-md` gaps) for Bot Team Overview cards.
- **Thumb Zone Compliance:** Key execution anchors (e.g., audio triggers, interrupt buttons, input bars) sit between 48px and 112px above the bottom gesture navigation bar, suspended in a glass-frosted interaction dock.

## Elevation & Depth

### Tonal Layers & Boundaries
- Surface levels achieve depth through subtle brightness stepping rather than heavy muddy drop shadows:
  - Surface 0: Pitch canvas (`#000000` / `#FAF8F5`).
  - Surface 1: Base cards (`#0A0A0C` / `#FFFFFF`) with crisp inner hairlines (`1px solid rgba(255,255,255,0.06)` or `rgba(0,0,0,0.05)`).
  - Surface 2: Raised bot drawers and popovers (`#141418` / `#F3EEE8`).

### Kinetic Glow System (Agent Halos)
Agent state elevation uses colored soft radiuses (`box-shadow: 0 0 28px -4px [BotColorGlow]`):
- **Atlas Glow:** `0 8px 32px -4px rgba(58, 134, 255, 0.35)`
- **Clara Glow:** `0 8px 32px -4px rgba(6, 214, 160, 0.35)`
- **Nico Glow:** `0 8px 32px -4px rgba(131, 56, 236, 0.35)`
- **Sora Glow:** `0 8px 32px -4px rgba(255, 89, 100, 0.35)`
- **Maya Glow:** `0 8px 32px -4px rgba(255, 190, 11, 0.35)`

### Glassmorphism
Floating action bar and prompt shells use hardware-accelerated blur:
- `backdrop-filter: blur(24px) saturate(180%)`
- Background: `rgba(10, 10, 12, 0.78)` (Dark) | `rgba(250, 248, 245, 0.82)` (Light)
- Perimeter hairline stroke: `1px solid rgba(255, 255, 255, 0.1)` (Dark) | `1px solid rgba(0, 0, 0, 0.06)` (Light)

## Shapes
The system uses rounded level `3` (pill-dominant aesthetic). Softness communicates friendliness and organic life:
- **Major Surfaces & Agent Cards:** `24px` to `28px` corner radiuses (`rounded-xl` to custom `rounded-28`).
- **Interactive Controls & Status Chips:** Full pill capsule (`9999px` / `rounded-full`).
- **Bot Morphology (Living Silhouettes):**
  - **Atlas:** Organic fluid drop / asymmetric blob (32px top-left, 16px top-right, 32px bottom-right, 28px bottom-left).
  - **Clara:** Smooth pill-octagon (soft, mathematically grounded angles).
  - **Nico:** Rounded dynamic triangle (high-radius corner vertices).
  - **Sora:** Tilted pill-capsule shield.
  - **Maya:** Perfect breathing circle with micro-fluid ripples.

## Components

### 1. Bot Avatar & Status Canvas
- **Visual Presentation:** A vector container (48x48px mobile compact, 88x88px agent card view) displaying the designated shape morphology. Inside, two minimal optical dots/dashes represent the companion's eyes.
- **Bot States (Brazilian Portuguese):**
  - **Trabalhando:** Ambient breathing scale animation (1.0 to 1.05 scale over 2.4s ease-in-out), synchronized glow casting the agent's signature color, eyes blinking rhythmically.
  - **Aguardando você:** Stable shape with an Electric Amber (`#FF9F1C`) micro-pulse badge / antenna wave at the upper-right corner.
  - **Dormindo:** Deep low-contrast tint (`opacity: 0.45`), eyes morph into two minimal horizontal dashes (`— —`), glow completely disabled.
  - **Erro / Bloqueio:** Warning orange-red outline ping (`#FF5964`), rapid subtle horizontal shake micro-haptic.

### 2. Primary & Action Buttons
- **Shape:** Pill shape (`border-radius: 9999px`).
- **Dimensions:** Minimum 52px height for primary mobile actions; 40px for secondary inline triggers.
- **Variants:**
  - *Primary System:* Solid Electric Amber (`#FF9F1C`), text `#000000` (bold 600).
  - *Agent Primary:* Filled with specific agent hex (e.g., Cobalt Blue for Atlas), text `#FFFFFF` or high contrast `#000000`.
  - *Ghost / Frosted Secondary:* Translucent background (`rgba(255,255,255,0.06)` in dark mode, `rgba(0,0,0,0.05)` in light mode), bordered by `1px solid rgba(255,255,255,0.12)`.

### 3. Agent Activity & Routine Cards
- **Structure:** 24px rounded rectangles with deep `#0A0A0C` background, hairline surface borders, and left-anchored vertical agent accent light bar (3px width, agent color).
- **Header:** Bot avatar (32px), Bot Name (`headline-sm`), status chip pill (`label-caps`).
- **Content:** Task description in Portuguese (`body-md`), elapsed time or battery/processing indicator (`label-mono-sm`).

### 4. Status Chips & Telemetry Badges
- **Form:** Pill (`padding: 4px 12px`).
- **Content:** Optional leading 6px pulsing dot + uppercase label (e.g., `EM EXECUÇÃO`, `PAUSADO`, `AGUARDANDO VOCÊ`).
- **Style:** Background tinted with 12% opacity of the associated agent color; text matching the full 100% agent hex.

### 5. Input Dock (Omni-Prompt Field)
- **Position:** Floating 16px above bottom screen margin.
- **Glass Shell:** `backdrop-filter: blur(24px)`, rounded `28px`, border `1px solid rgba(255,255,255,0.14)`.
- **Elements:** Leading agent routing icon selector (switch between "Todos", "Atlas", "Clara", etc.), placeholder "Peça algo para sua equipe...", and trailing microphone/send pill button with Electric Amber accent.

### 6. Lists & Routine Toggles
- **List Items:** Row padding `16px 20px`, separated by hairline divider `rgba(255,255,255,0.04)`.
- **Toggles:** 50px pill switches; thumb scales down slightly on drag; active track switches to Nico Violet (`#8338EC`) when managing device routines or Electric Amber for master system toggles.
